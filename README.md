# Jotify Notes

Clear Your Mind & Chaos With Jotify. A minimal, cozy full-stack note-taking app designed to capture quick thoughts, pin high-priority items, and organize your daily life with a comforting visual style.

---

## Features

* Secure User Authentication: Full signup and login system with token handling to keep your notes private and isolated per user account.
* Note Pinning: Pin important notes to the top of your workspace for easy, instant access.
* Custom Pastel Color Palettes: Assign soothing custom colors to each note card to visually categorize your thoughts.
* Full CRUD Functionality: Create, read, update, and delete notes with instant client-side updates.
* Comforting Visual Interface: Custom theme aesthetics featuring soft typography, smooth dark-mode UI elements, and subtle card shadows.

---

## Tech Stack

### Frontend
* React (Vite)
* Tailwind CSS

### Backend
* Node.js & Express.js
* PostgreSQL
* JSON Web Tokens (JWT) for authentication
